# SonicSentinel AI — Interactive Notebooks

This directory contains Jupyter Notebooks developed to support data exploration, acoustic analysis, feature engineering, and model training.

## Notebook Index
1. **`01_exploratory_audio_analysis.ipynb`**:
   - Class balance and distribution across splits (70% Train, 15% Val, 15% Test).
   - Audio waveform and Mel Spectrogram visualization across the classes (10 mandatory + 7 optional since 27 Sep 2026).
   - Demonstration of the 193-dimensional handcrafted acoustic feature vector.
   - Feature correlation and variance analysis.

To run these notebooks locally:
```bash
jupyter notebook notebooks/
```
