    What happens to a file

    1. Validation — format, size, duration, sampling rate, channels, integrity and presence of sound. Silent, damaged or unsupported files are rejected with the reason.
    2. Pre-processing — mono, resampling to {{ 22050 }} Hz, noise reduction, silence trimming, normalisation, {{ segmentation.segment_seconds|round(1) }} s segments.
    3. Python model — 193 acoustic features per segment (MFCC, mel spectrogram, chroma, energy, spectral shape, onsets, pitch).
    4. Teachable Machine — runs in your browser on the same segments, without seeing the Python result.
    5. Decision — comparison, audio quality, alert rules and manual-review routing.
