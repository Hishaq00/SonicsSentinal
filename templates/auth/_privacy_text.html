Privacy notice

Audio, microphones and your data

SonicSentinel AI analyses sound to detect events such as alarms, breaking glass or calls for help. Sound can contain voices, so we handle it carefully.

The microphone is never used secretly

  • Live monitoring starts only when you press Start monitoring and your browser has granted microphone permission.
  • While it runs, a red Microphone on indicator is shown on every page and the browser shows its own recording indicator.
  • You can pause or stop at any time. Closing the tab stops the microphone.
  • Before the first session you are asked to confirm you have read this notice.

What is stored

  • Uploaded files: the original file, a pre-processed copy, a waveform and a spectrogram image, the predictions of both models and the final decision.
  • Live windows: every prediction is stored. The audio itself is stored {% if settings.live.store_audio == "all" %}for every window{% elif settings.live.store_audio == "none" %}never (predictions only){% else %}only for windows in which an event was detected{% endif %} (administrator setting).
  • Audit trail: sign-ins, uploads, microphone sessions, predictions, alerts, reviews, overrides and exports, with time and IP address.

How long data is kept

  • Uploaded audio: {{ settings.retention.audio_days }} days.
  • Live audio: {{ settings.retention.live_audio_days }} days.
  • Event records (predictions, alerts, reviews): {{ settings.retention.records_days }} days.

After these periods the data is deleted automatically. Administrators can change the periods.

Who can see it

Normal users see their own recordings. Reviewers, security and maintenance operators see events they are responsible for. Administrators manage the system. Audio files are stored outside the public web folder and are only served to signed-in users with permission.

Ethical use

  • Only monitor places where you are allowed to, and tell people that sound monitoring is in use.
  • Do not use the system to identify or profile individuals.
  • Speech samples in the training data were recorded voluntarily, synthesised, or taken from licensed sources.
  • This is a competition prototype. It is not a certified emergency-response or law-enforcement system; in an emergency call your local emergency number.
