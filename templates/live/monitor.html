Before you start the microphone

SonicSentinel will listen through this device's microphone and analyse the sound in short windows to detect events such as alarms, breaking glass or calls for help.

  • A red Microphone on indicator is visible while monitoring runs. You can pause or stop at any time.
  • {% if live.store_audio == "events" %}Only windows with a detected event are stored{% elif live.store_audio == "all" %}Every window is stored{% else %}No audio is stored{% endif %}; audio is deleted after the retention period.
  • Only monitor places where you are allowed to, and tell people nearby that sound monitoring is active.
