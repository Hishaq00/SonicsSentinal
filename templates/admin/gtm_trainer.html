Teachable Machine training helper

Teachable Machine audio projects learn from sound recorded through a microphone. This page plays the exported training samples of one class at a time so you can record them into the matching Teachable Machine class. The samples come only from the training split, the same recordings the Python model was trained on. To train the same Teachable Machine network without a microphone, run python -m scripts.train_gtm_model: it uses the exact input the browser computes and reports test-set accuracy.

Steps

  1. Run python -m gtm_model.export_gtm_samples (already done if the table shows samples).
  2. In Teachable Machine create an Audio project. Rename the classes to exactly the names in the table (case and spaces matter). "Background Noise" already exists.
  3. Route this page's sound into the Teachable Machine microphone: best with a virtual audio cable (e.g. VB-CABLE: set it as this browser tab's output and as Teachable Machine's input); otherwise play through speakers in a quiet room.
  4. In a class, set the recording length to 20 s, press Record and immediately press Play here for the same class. Extract the samples. Repeat until all samples of the class are recorded.
  5. Train the model (defaults: 50 epochs, batch 16, learning rate 0.001), then Export → TensorFlow.js → Download (or Upload for a shareable link).
  6. Unzip model.json, metadata.json and weights.bin into gtm_model/model/, or paste the link on the Models page. The label check there must say the class names match.

Full guide with screenshots checklist: gtm_model/README.md.
