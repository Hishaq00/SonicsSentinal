Adding real recordings

  1. Put files in audio_dataset/incoming/<class_slug>/ (for example audio_dataset/incoming/gunshot/). Optional details go in audio_dataset/incoming/metadata.csv (filename, environment, device, distance_m, source, license, speaker, notes).
  2. Run python -m scripts.build_dataset — files are validated, de-duplicated, given Audio IDs and split 70/15/15 without changing existing splits.
  3. Run python -m augmentation.augment_dataset, python -m feature_extraction.build_features and python -m python_models.train.
  4. Run python -m scripts.train_gtm_model to retrain the GTM model on the same splits (needs requirements-gtm.txt), or run python -m gtm_model.export_gtm_samples and retrain it in Teachable Machine with the new training samples.
